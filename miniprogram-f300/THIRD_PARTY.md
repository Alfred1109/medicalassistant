# Third-party software

The `miniprogram/libs/veepoo/` bundle and declaration file are copied from
[HBandSDK/WeChat_Mini_Program_Ble_SDK](https://github.com/HBandSDK/WeChat_Mini_Program_Ble_SDK),
commit `ad2f60c258fa09f7d3d34cdeb2e32b8baf7664dd` (SDK V1.2.1, 2026-11-13).
The repository identifies its license as Apache-2.0; see `LICENSE-Veepoo-Apache-2.0`.
The upstream README limits the SDK to Veepoo smart wearable products and says device
compatibility must be confirmed with Veepoo. This prototype was tested with an F300
firmware reported as `00.37.03.00-5272`; that does not establish compatibility with
other models or clinical accuracy.
